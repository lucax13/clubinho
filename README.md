# Clubinho

projeto de uma aplicação Web SPA usando Next.js, Typescript e SupaBase (Baas - Back-end as a Service).

## 00_projeto-zerado

Ajuste e remoções de elementos da instalção padrão do next.js

### revisando topicos importantes

- src/ap/page.tsx: página principal (index, home). Obs.: o nome do arquivo **precisa ser** `page.tsx`, mas o nome interno (na função) pode ser qualquer um.

- `src/app/layout.tsx`: componente/arquivo especial que a estrutura padrão (layout) para todas as páginas.
